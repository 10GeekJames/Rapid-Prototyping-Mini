# Personal Website

A simple dark-themed webpage that displays user input in large text.

## Usage

1. Open `index.html` in your browser.
2. Type in the input box. Your text will appear very large on the screen.

## Tech
- Tailwind CSS (https://cdn.tailwindcss.com)
- DaisyUI (https://cdnjs.cloudflare.com/ajax/libs/daisyui/5.1.25/daisyui.css)
- Vanilla JavaScript
